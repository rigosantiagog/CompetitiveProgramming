Pestaña 01 · Fundamentos de Memoria

¿Cómo entiende la computadora un Número o una Letra?

En la memoria RAM todo se guarda mediante interruptores microscópicos llamados bits que solo tienen dos estados: 1 (Encendido) o 0 (Apagado). Un grupo de 8 bits forma 1 Byte, y cada posición vale el doble que la anterior (2⁰, 2¹, 2²... 2⁷). ¡Toca los interruptores de abajo para construir tus propios números y caracteres!

EL SECRETO DE C++

Los mismos 8 bits 01000001 representan el número entero 65 si usas un tipo numérico, o la letra 'A' si usas un tipo char (Código ASCII).
